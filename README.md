## Practice Rules

For every problem:
1. Understand the problem.
2. Write the logic in your own words.
3. Implement the solution in Python.
4. Test normal and edge cases.
5. Record time and space complexity.
6. Re-solve without looking at the solution.

## Goal

Build strong problem-solving skills for internships and software engineering placements.
